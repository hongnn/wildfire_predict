Google Maps API Key 申请流程
==========================

时间：2026-06-26


第一步：注册 Google Cloud 账号
--------------------------------
1. 打开 https://console.cloud.google.com/
2. 用 Google 账号登录（没有的话先注册一个 Gmail）
3. 首次使用会提示启用结算功能（需绑定信用卡/借记卡进行身份验证）


第二步：创建项目
--------------------------------
1. 顶部导航栏点击项目下拉菜单 -> 新建项目
2. 项目名称填 wildfire-forecast（或其他），点击"创建"
3. 等待几秒，顶部通知栏会提示项目创建成功


第三步：启用 Maps JavaScript API
--------------------------------
1. 确保已选中刚创建的项目
2. 左侧菜单 -> API 和服务 -> 库
3. 搜索框输入 Maps JavaScript API
4. 点击该 API -> 点击"启用"


第四步：创建 API Key
--------------------------------
1. 左侧菜单 -> API 和服务 -> 凭据
2. 点击顶部"+ 创建凭据" -> API 密钥
3. 密钥创建成功后会弹出窗口，复制保存这个 Key（格式：AIzaSyD-xxxxxx）


第五步：限制 API Key（强烈建议，防止泄露后被滥用）
--------------------------------
1. 在凭据页面，点击刚创建的 Key 进行编辑
2. 设置应用限制：选择"HTTP 引用来源（网站）"，添加你的域名
3. 设置 API 限制：下拉选择 Maps JavaScript API（只允许这一个 API）
4. 点击"保存"


费用说明
--------
- 免费额度：每月 $200 等值免费额度
- Maps JavaScript API：$7 / 1000 次加载
- 免费额度约等于：每月 ~28,000 次地图加载
- 超出后：按量付费，可在控制台设置预算告警
- 可设置每日配额上限防止意外超支


拿到的 API Key 后请保存好，后续接入项目使用。
